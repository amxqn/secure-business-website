What is protected

Six protections are already in place on this site.

  • 01

    HTTPS everywhere

    The site is served over an encrypted connection, so data can't be read or changed on its way to the visitor.

    In place
  • 02

    Content Security Policy

    Set with a meta tag on every page, so the browser only loads scripts and styles from this site. This limits the damage if malicious code were ever injected.

    In place
  • 03

    Input validation

    The contact form checks name, email and message for length and format before anything is sent.

    In place
  • 04

    Safe output

    Error messages are written as plain text, never as HTML, which blocks cross-site scripting through the form.

    In place
  • 05

    Bot filtering

    A hidden honeypot field catches simple spam bots without making real visitors solve puzzles.

    In place
  • 06

    No third-party code

    No outside fonts, trackers or libraries, so there is less code from other people to trust.

    In place

What a scan found

The live site was scanned with securityheaders.com on 3 October 2026. The grade is low, and the reasons are explained below.

Overall grade
D
Passed
Strict-Transport-Security, which tells browsers to always use HTTPS. GitHub Pages sends this one automatically.
Flagged
Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy and Permissions-Policy.
Why
GitHub Pages doesn't let site owners set custom HTTP headers. The Content Security Policy is set with a meta tag on every page, but the scanner only reads real headers, so it still reports it as missing. A meta tag also can't set clickjacking protection, which needs a header.

What comes next

Three improvements are planned.

  • A

    Cloudflare in front

    A free plan can add the five missing headers as real HTTP headers, and a second scan can show the grade improving.

    Planned
  • B

    Server-side checks

    Browser checks can be bypassed, so a real site must validate on the server too. Formspree handles this for the demo.

    Planned
  • C

    Deeper audit

    Test the site against the OWASP Top 10 with OWASP ZAP and write up the findings.

    Planned
