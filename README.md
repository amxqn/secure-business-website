# Secure Business Website

A demo website for a fictional Sharjah coffee house, built to practice combining web design with cybersecurity.

**Live site:** https://YOURUSERNAME.github.io/secure-business-website

## About

Small businesses often have websites that look fine but aren't protected. This project builds a simple business site and adds security features step by step, documenting what each one does and why it matters.

## Built with

- HTML
- CSS
- GitHub Pages (hosting and HTTPS)
- VS Code and Git
